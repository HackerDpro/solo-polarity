# Solo Polarity

Attract and repel through AI bot waves. Built for Hack Club Terra.

## Play

We don't have a public link yet!!!

## Controls

| Action  | Key                     |
| ------- | ----------------------- |
| Move    | WASD / Arrow Keys       |
| Attract | Hold Left Mouse Button  |
| Repel   | Hold Right Mouse Button |
| Pause   | Esc                     |

## Features

- Attract/repel field physics
- Bot-vs-bot chaos
- Tiers that transform your abilities
- Endless wave survival with scaling difficulty

## 🛠️ Stack

Vanilla JS (ES Modules) + HTML5 Canvas 2D + Vite

## 🚀 Local Dev

\`\`\`bash
git clone https://github.com/<you>/solo-polarity.git
cd solo-polarity
npm install
npm run dev
\`\`\`
